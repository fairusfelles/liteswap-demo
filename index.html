LiteSwap — concept demo. This page is a browser-local simulation: real AMM maths (x·y=k, 0.3% fee) run against a simulated pool held in this tab, while the reference price is the live mainnet LTC/USDT rate from Kraken. No contracts are deployed on LiteForge, no real funds move, all balances and trades here are simulated, and no wallet is ever asked for a signature. In the deployed version, the same reference feeds an on-chain pool on LiteForge and the keeper keeps it at parity.
